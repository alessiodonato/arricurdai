Add a middleware `MethodAllowList(methods ...string) func(http.Handler) http.Handler` in a new file middleware/method_allow_list.go. Requests whose method is in the list go to the next handler. Any other request gets 405 Method Not Allowed with an `Allow` header that lists the allowed methods, comma separated, and never reaches the next handler. Add table-driven tests in middleware/method_allow_list_test.go and run `go test ./middleware/` until it passes.
