Why sessions get expensive

The context is paid for on every call.

A coding agent sends the model everything it has read and said so far, on every call. The prompt cache makes that cheaper, but not free, and it forgets after an hour.

1

Each call reads it all again

A session that has gathered 500,000 tokens pays to read all of them on every call: about $0.10 per call with Opus 5.5, before the model writes a word.

2

A pause empties the cache

After an hour away, the next prompt writes the whole context to the cache again, at twice the input price. That one call costs as much as reading the context forty times.

3

Start fresh, carry a note

A new session starts from the system prompt and a short note on the old one. The agent reads files again only when it needs them, so every later call is cheaper too.

What it does

One profiler, two hooks.

The profiler tells you where the tokens go. The hooks act on the biggest waste it finds, without changing how you work.

command

profile: see where the tokens go

The cost of every session, weighted by price. Which blocks of context carry it. What compacting at other moments would have saved. Memory lines never used, and files read again.

arricurdai profile --project .
hook · UserPromptSubmit

guard: stop the costly resume

When the cache of a session over 100,000 tokens has expired, it stops your first prompt once and shows what going on would cost. Send it again to go on.

arricurdai guard --min-tokens 100000
hook · SessionStart

handoff: start fresh, keep the thread

After that /clear, it gives the new session a note built from the transcript, without a model: the last requests, the files changed, the open tasks and the last reply. It also tells every new session how to run recall, which searches past sessions.

arricurdai handoff

Without pauses, compacting cost more than it saved: a summary is paid at the output price, five times the input price. The whole experiment

  • Context size and pauses are what costReading a large context on every call, and writing it again after a pause, outweigh everything else in long sessions.
  • Rediscovery is cheapOn three public repositories, re-reading what the agent already knew was 4–6% of the tokens. Better memory alone could save at most 1.2%.
  • Prices from the sourceOn Claude 5 models a cache read costs 0.05 of an input token, not 0.1, as the costs Claude Code records show.

Start

Measure first, then let the hooks work.

It needs Node 20 or later and pnpm. It is not on npm yet, so build it from a clone.

1. Build and profile

git clone https://github.com/alessiodonato/arricurdai
cd arricurdai
pnpm install && pnpm build
node packages/cli/dist/bin.js profile --project /path/to/project

New here? The guide explains every part of the report.

2. Add the hooks

In ~/.claude/settings.json, or .claude/settings.json for one project:

{
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command",
      "command": "node /path/to/arricurdai/packages/cli/dist/bin.js guard" }] }],
    "SessionStart": [{ "hooks": [{ "type": "command",
      "command": "node /path/to/arricurdai/packages/cli/dist/bin.js handoff" }] }]
  }
}

On any problem the hooks let the prompt through.
